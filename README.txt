HOW TO OPEN (no server needed)
------------------------------
1. Double-click index.html — it opens in any browser (Chrome, Edge, Safari, Firefox).
2. On Android: download the folder/zip, open index.html in your Files app.

TO SWAP ANY PHOTO
-----------------
Replace the file below with another image, keeping the SAME filename
(any common format works: .jpg / .png). Portraits look best in 4:5
(portrait) orientation, e.g. 800x1000px.

  images/victor.jpg         -> Victor Kehinde (Visionary)
  images/demindsurgeon.jpg  -> Demindsurgeon (Thought Leader)
  images/clergyunusual.jpg  -> ClergyUnusual (Revolutionary)
  images/victor-ministry.jpg-> About section photo
